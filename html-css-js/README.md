## Thinks that we can learn from these projects

### 1. To-Do List (Habit Tracker)

- CURD Operations
- Persistent storage - Local storage
- Date Logic
- Dynamic webpage
- High order array functions - map & filter
- Add event listener and event handling
- DOM manipulation

### 2. Personal Finance Engine

- CURD operations
- Persistent storage - Local storage
- Data formatting and validation
- Dynamic table rendering
- Real-time calculations (income, expense, balance)
- Array methods for data filtering and aggregation
- Date manipulation and formatting
- Event delegation for edit and delete operations

### 3. Weather Forecast App

- Async/Await and Promises
- API integration (OpenWeatherMap API)
- Fetch API for HTTP requests
- Error handling and user validation
- DOM element creation and manipulation
- Destructuring from API responses
- Loading states
- Dynamic UI updates based on API data

### 4. Multiplayer Quiz Game

- Advanced event handling and state management
- Local storage for multi-user data persistence
- Local storage event listeners for real-time synchronization
- Session storage for identifying players
- JSON file handling and async data loading
- Game state management (lobby, game, results)
- Timer and scoring logic
- Dynamic rendering of game UI based on game state
- Player management and leaderboard functionality
- Error handling for data loading and parsing
